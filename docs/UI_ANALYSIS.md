## 🔍 Что делает MedKit (анализ скриншотов)

### Экран 1: Лендинг (medkit-app.vercel.app)
- Тёплый персиковый фон (`#F5E6D3`)
- Крупный логотип с тенью и розовым крестом
- Бейдж "1st place · Anthropic Built with Opus 4.7"
- Слоган: *"The clinic that lets you make every mistake before they count."*
- Две кнопки: Watch demo + Try it live
- Декоративные элементы: облака, солнышко, звёздочки, сердечко
- Волнистый зелёный низ страницы
- Переключатель (тоггл) в правом углу — тёмная тема

### Экран 2: Выбор режима (коридор)
- Три большие карточки-двери: Polyclinics / Services / Emergency
- Polyclinics — зелёная, открыта ("Open now · 24 specialties")
- Services и Emergency — серые, заблокированы ("Coming soon")
- Изометрический пол с перспективой
- Растения по углам
- Шапка: логотип + режим "Polyclinic" + имя пользователя

### Экран 3: Как начать приём
- Вопрос: "How would you like to start?"
- Два варианта в карточках:
  - **01 · ACCEPT** — принять следующего пациента (зелёная карточка)
  - **02 · BROWSE** — выбрать из папки дел (синяя карточка)
- Показывает предварительный просмотр: имя пациента + диагноз + специальность
- "240 cases · filterable"

### Экран 4: Выбор пациента (Pick a patient)
- Горизонтальная прокрутка по специальностям (фильтры-чипы сверху)
- 24 специальности: Internal Medicine, Cardiology, Neurology...
- Кнопка "Shuffle (240)" — случайный пациент
- Карточки пациентов: цветной фон, иллюстрация персонажа, имя/возраст/пол
- Цитата жалобы пациента в кавычках
- Бейдж специальности + "Polyclinic"
- Цвета карточек по заболеванию: жёлтый, оранжевый, зелёный, голубой, розовый

### Стиль иллюстраций пациентов
- Простые мультяшные персонажи
- Разные цвета кожи, одежда
- Нейтральные выражения лиц
- Однотонный цветной фон карточки

## 🎨 KazMedSim: Свой дизайн (НЕ копировать MedKit)

### Концепция
**MedKit** = западная мультяшная клиника, игривый стиль
**KazMedSim** = казахстанский медицинский центр, профессиональный но дружелюбный

Вдохновение: казахский орнамент + современный медицинский UI + Central Asian aesthetic

### Цветовая палитра KazMedSim
```css
--primary: #1B6CA8;        /* синий — медицина */
--primary-light: #EBF4FF;  /* светло-синий фон */
--accent: #E8A317;         /* золотой — казахский акцент */
--accent-light: #FFF8E7;   /* светло-золотой */
--success: #2D9E6B;        /* зелёный — здоровье */
--danger: #D94F3D;         /* красный — важное */
--bg: #F7F9FC;             /* почти белый фон */
--card: #FFFFFF;           /* белые карточки */
--text: #1A2332;           /* тёмно-синий текст */
--text-muted: #6B7A8D;     /* серый второстепенный */
--border: #DDE3EC;         /* граница */

/* Казахский орнамент акцент */
--ornament: #C8963C;       /* бронзовый */
```

### Шрифты
```css
/* Заголовки */
font-family: 'Golos Text', 'Inter', sans-serif;  /* поддерживает кириллицу */

/* Тело */
font-family: 'Inter', 'Nunito', sans-serif;
```

### Декоративные элементы (вместо облаков MedKit)
- Тонкий казахский геометрический орнамент в углах (SVG, не доминирует)
- ЭКГ-линия как разделитель секций
- Пульс-анимация на кнопке "Начать приём"
- Иконки: медицинский крест, стетоскоп, молекула

## 🛠️ Реализация в коде

### Компонент аватара пациента (вместо иллюстраций)
```tsx
// Аватар с инициалами и уникальным цветом по имени
const AVATAR_COLORS = [
  '#1B6CA8', '#2D9E6B', '#E8A317', '#D94F3D', '#7B5EA7'
];

function PatientAvatar({ name }: { name: string }) {
  const color = AVATAR_COLORS[name.charCodeAt(0) % AVATAR_COLORS.length];
  const initials = name.split(' ').map(n => n[0]).join('').slice(0, 2);
  return (
    <div style={{ background: color }} className="avatar">
      {initials}
    </div>
  );
}
```
